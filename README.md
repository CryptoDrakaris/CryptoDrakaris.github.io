# Drakaris

**Сайт:** https://cryptodrakaris.github.io/

Личный сайт NFT-коллекционера `drakaris.eth`: вся коллекция кошелька на трёх языках (RU, KZ, EN).
Флагманские проекты — каждый в своём фирменном стиле, остальное — в разделе «Другие».

Правила проекта и все принятые решения: [CLAUDE.md](CLAUDE.md).

## Локальная работа

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
```

## Обновление коллекции

После покупки или продажи NFT:

```bash
npm run fetch    # читает кошелёк, скачивает новые оригиналы
npm run derive   # готовит превью и акцентные цвета
npm run build
```

Затем закоммитить изменения в `data/` и `public/derived/` и запушить — сайт пересоберётся сам.

## Публикация на GitHub Pages

Делается один раз.

1. Создать на GitHub **пустой репозиторий** (можно приватный, Pages работает и с приватными на платном тарифе; для бесплатного — публичный).
2. Привязать его и отправить код:

   ```bash
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Открыть вкладку **Actions** и дождаться зелёной галочки. Адрес сайта появится там же и в Settings → Pages.

Дальше каждый `git push` в ветку `main` публикует обновление автоматически.

### Адрес сайта

- Репозиторий с именем `<логин>.github.io` → сайт будет на `https://<логин>.github.io/`.
- Репозиторий с любым другим именем → `https://<логин>.github.io/<репозиторий>/`.

Подставлять адрес в код не нужно: сборка сама подставит его в canonical-ссылки, sitemap и пути к файлам
(переменные `SITE` и `BASE_PATH` в [.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

### Свой домен

Купить домен, в Settings → Pages указать его в Custom domain, у регистратора добавить записи:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 |
| CNAME | www | `<логин>.github.io` |

После проверки домена включить **Enforce HTTPS**.

## Что лежит в репозитории

- `data/collection.json`, `data/derived.json` — метаданные коллекции, нужны для сборки.
- `public/derived/` — превью (около 46 МБ), отдаются сайтом.
- `data/originals/` — оригиналы (около 335 МБ), **не** в репозитории: слишком тяжёлые, скачиваются заново командой `npm run fetch`.
