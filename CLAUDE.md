# Персональный сайт Drakaris

Личный сайт NFT-коллекционера `drakaris.eth` (ник Drakaris, @cryptodrakaris в X и TikTok). Показывает всю коллекцию кошелька: флагманы в фирменном стиле каждого проекта, остальное – в разделе «Другие». Аудитория – публичная: комьюнити проектов и все, кто увлекается NFT и web3. Владелец – он же заказчик и единственный редактор.

Проект личный. Корпоративные скилы `msn-style-text`, `msn-style-docx`, `msn-style-xlsx`, `msn-style-pptx` и правила медкластера здесь не применяются. Тексты сайта – свободный разговорный регистр, эмодзи и мемы допустимы.

## Принятые решения

### Структура (2026-09-15)

- **Оболочка Drakaris:** главная, «Коллекции», общая галерея, блог, «Обо мне», контакты – в собственном стиле владельца.
- **Флагманы** в порядке любви владельца, каждый на своей странице в фирменном стиле проекта:
  1. Lazy Lions – вся вселенная: Lions, Cubs, Scenes, Bungalows, Butts, Comics;
  2. Gray Boys;
  3. Bubblegum Kids + Bubblegum Puppies;
  4. Robotos + Robopets + TIMEPieces x Robotos;
  5. Nonconformist Ducks + Hell Ducks (ScorchingDucks);
  6. Adam Bomb Squad + Badam Bomb Squad;
  7. MarsCatsVoyage + Alien Cats + Mars Cats in Spacesuits.
- **«Другие»:** все остальные коллекции кошелька, кроме спама. Общий шаблон, акцентный цвет у каждой коллекции извлекается из её картинок (`derive`).
- **Скрыто:** спам-раздачи из `HIDDEN` в `scripts/config.mjs` (пустые метаданные, фишинговые домены). Новый подозрительный токен скрипт `fetch` выводит в конце лога для ручной проверки, но не скрывает сам.
- **Lazy Butts** выпустила сторонняя студия 3D Kings, но это дополнение к львам (нижняя часть), владелец попросил держать их во вселенной Lazy Lions. **Lazy Scenes** официальны: метаданные отдаёт `metadata.lazylionsnft.com` – тот же домен, что и у основной коллекции.

### Стек и роутинг

- Astro 7 (статическая генерация) + TypeScript, без Tailwind. Next.js отклонён как избыточный.
- Языки RU, KZ, EN. Роутинг вручную через `src/pages/[lang]/`, встроенный i18n Astro выключен. Корень `/` выбирает язык по браузеру, по умолчанию EN. Код языка в URL – `kk`, в переключателе «KZ».
- URL: `/[lang]/collections/` – список, `/[lang]/collections/<флагман>/` – страница флагмана, `/[lang]/collections/others/` – «Другие», `/[lang]/nft/<коллекция>/<tokenId>/` – токен.

### Темы

- Каждая страница ставит `<html data-theme>`, компоненты используют только токены из `src/styles/themes.css`. Реестр шрифтов – `src/lib/themes.ts`. Карточка флагмана на страницах оболочки несёт свой `data-theme` и рендерится в стиле бренда.
- **Drakaris:** тёплый почти чёрный `#0B0B0D`, текст `#F2EEE8`, акцент «тлеющий уголь» `#FF6A3D` (от «Dracarys»). Шрифты Unbounded (заголовки, логотип на всех темах) + Onest + JetBrains Mono.
- **Каноны флагманов** – из CSS живых сайтов или архивных копий в Wayback Machine (исследование 2026-09-15):
  - Lazy Lions: lazylionsnft.com, тёмный + золото;
  - Gray Boys: мятный `#D6F1F1` + зелёный, толстые мультяшные обводки;
  - Bubblegum Kids: розовый/жёлтый/фиолетовый, комиксные рамки и жёсткие тени;
  - Robotos: robotos.art, светлый + красный/жёлтый, смещённые тени;
  - Nonconformist Ducks: сайт 2026 года, тёмный «огонь» + жёлтый, без скруглений;
  - Adam Bomb Squad: красный/чёрный/белый/жёлтый, стритвир, рамки 3px;
  - MarsCatsVoyage: marscatsvoyage.com, почти чёрный `#131313`, космический синий `#0F2239`, оранжевый `#FF3200`, кнопки-таблетки, мягкие тени. Шрифт Sora без кириллицы, на RU/KK – Onest. Белый на их оранжевом даёт 3.7:1, поэтому `--accent-ink` тёмный.
- **Шрифты брендов:** платные или без кириллицы заменены ближайшими Google Fonts с кириллицей и казахскими буквами:
  - Gray Boys: Exo 2;
  - Bubblegum Kids: Nunito вместо akagi-pro;
  - Robotos: Rubik + IBM Plex Mono вместо Right Grotesk и Space Mono;
  - Adam Bomb Squad: Open Sans Condensed;
  - Space Grotesk и Anton без кириллицы: на RU/KK вся страница переключается на Onest/Oswald, чтобы в строке не смешивались шрифты.
- **Контраст:** фирменные цвета, не проходящие 4.5:1 как текст, затемнены или осветлены с пометкой в `themes.css` (красный Robotos и ABS, серый Ducks).
- **Официальность:** логотипов проектов нет. На странице каждого флагмана и в подвале пометка «не связан с проектом». Тексты о проектах пересказаны своими словами, источники перечислены в `src/content/flagships.ts`.

### Прочее

- **Контакты:** только ссылки (X, TikTok владельца + официальные каналы флагманов). Формы нет: у статического хостинга нет бэкенда.
- **Хостинг:** бесплатный, выбирается перед публикацией (Netlify или GitHub Pages). После выбора прописать `site` в `astro.config.mjs`, тогда появятся canonical и абсолютные og:image.
- **Скил `ui-ux-pro-max`** не устанавливается. Его правила переработаны в проектный скил `.claude/skills/web-design-audit`, пока только для этого проекта. Полный аудит – после доработок, перед публикацией. Находки пробного прогона (серый 3.3–3.5:1, текст 11.5px, кнопки языков 32×28, h1→h3 в блоге) учтены в новой оболочке, но нужна проверка аудитом.

## Команды

```bash
npm install          # зависимости проекта
npm run fetch        # собрать токены и оригиналы в data/ (лог: node scripts/fetch-collection.mjs > data/fetch.log)
npm run derive       # webp-копии в public/derived/ + акцентные цвета в data/derived.json
npm run dev          # локально: http://localhost:4321
npm run build        # сборка в dist/
```

## Структура

```
scripts/
  config.mjs              # владелец, RPC, индексатор, IPFS-шлюзы, FLAGSHIPS, HIDDEN, METADATA_SERVICES
  fetch-collection.mjs    # задача 1: поиск токенов, проверка владения, метаданные, оригиналы
  derive-images.mjs       # webp 600px (статичный первый кадр) и 1600px + акцент коллекции
data/
  collection.json         # группы → коллекции → токены, в репозитории
  derived.json            # какие превью есть, размеры, акцентные цвета, в репозитории
  originals/<contract>/   # оригиналы, в .gitignore, не трогать
public/derived/<contract>/<tokenId>-{grid,full}.webp
src/
  i18n/ui.ts              # строки оболочки на трёх языках + plural
  content/flagships.ts    # тексты, факты, ссылки и тема каждого флагмана на трёх языках
  content/blog/<lang>/<slug>.md
  styles/themes.css       # токены тем; global.css – общие стили
  lib/                    # site.ts, collection.ts, themes.ts, blog.ts
  components/             # Header, Footer, NftCard, GroupCard, JoinBand, PostList, Icon
  layouts/Base.astro      # theme, brand, accent, extraThemes
  pages/[lang]/           # index, collections/{index,[slug],others}, nft/[collection]/[id], gallery, about, contact, blog/
```

Новая запись в блоге: `src/content/blog/<lang>/<slug>.md` с полями `title`, `description`, `date` (`draft: true` – скрыть). Слаг одинаковый во всех языках.

Новый флагман: добавить группу в `FLAGSHIPS` (`scripts/config.mjs`), тему в `themes.css` и `themes.ts`, тексты в `flagships.ts`, затем `npm run fetch && npm run derive`.

## Задача 1. Сбор коллекции

- `drakaris.eth` → `0xE71859A7D000648D397b6F1A33b491BD38f26eF3`, адрес закреплён в конфиге.
- Список токенов – публичный API Blockscout без ключа. Владение каждого токена проверяется в контракте (`ownerOf` / `balanceOf` через multicall), `tokenURI`/`uri` читается из контракта. Метаданные из индексатора – только запасной вариант, источник записан в `metadataSource`.
- Особые случаи:
  - ENS – метаданные с metadata.ens.domains;
  - on-chain SVG из `image_data`;
  - тип файла определяется по содержимому, а не по заголовку сервера (NonconformistDucks отдают PNG как JPEG);
  - поддоменные IPFS-шлюзы (`<cid>.ipfs.nftstorage.link`) переписываются на общий список шлюзов.
- **Мёртвые серверы проектов** (StreetDawgs, DaVinci by AML, 3D Kings / Lazy Butts, ENS-имя): оригиналов нет, токены показываются с заглушкой.
- **Спасение картинок.** Если сервер проекта мёртв безвозвратно, источник прописывается в `IMAGE_OVERRIDES` (`scripts/config.mjs`), файл скачивается один раз и хранится у нас. В `imageSource` пишется происхождение: `original`, `archive` (веб-архив), `marketplace` (копия с маркетплейса, пережата). На странице токена источник показывается явно, чтобы пережатая копия не выдавалась за оригинал. Хотлинк запрещён: у таких CDN стоит проверка Referer.
  - Crypto Cannabis Club: оригиналы существовали только на сервере проекта (в контракте на IPFS лежит лишь заглушка «Secret: Hidden», `baseURI` с 2021-08-06 указывал на их API). #1636 взят из Wayback Machine, #2086, #5211, #9624 – копии с Blur, все 4096×4096.
- **IPFS.** Публичные шлюзы ограничивают частоту (429), `ipfs.io` и `dweb.link` отдают Cloudflare-челлендж. Отдельно проверено: CID картинок Lazy Scenes больше никто не хранит (`delegated-ipfs.dev` показывает ноль провайдеров), вернуть файлы оттуда нельзя.
- **Lazy Scenes:** метаданные – с живого `metadata.lazylionsnft.com` (`METADATA_SERVICES`), картинки – PNG 3000×4600 с Blur (`marketplace`). Данные индексатора по этой коллекции устарели: они с этапа до раскрытия, где у всех токенов один `0.mp4`.
- **Lazy Butts:** инфраструктура 3D Kings мертва, S3-бакет закрыт. Картинки – AVIF 1600×1600 с Element (`marketplace`), метаданные – из индексатора.
- **Запасной путь через curl.** CDN Element отвергает соединения Node (проверяет отпечаток TLS) и принимает заголовок только в каноническом написании `User-Agent`, а не `user-agent`. Поэтому `fetchWithFallback` в крайнем случае вызывает `curl` (`curlGet`), передавая user-agent ключом `-A`.
- **Определение типа файла:** AVIF и HEIC имеют тот же заголовок `ftyp`, что и mp4, поэтому тип уточняется по «бренду» внутри заголовка, иначе картинка сохранялась бы как видео и выпадала из превью.
- Скрипт идемпотентный: повтор докачивает недостающее. После новых покупок: `npm run fetch && npm run derive && npm run build`.

## Задача 2. Сайт

Требования, которые должны сохраниться:

- В сетках только `derived` 600px, статичный первый кадр, `loading="lazy"`. Видео и GIF в сетке не проигрываются, на странице токена – 1600px (GIF анимирован). Оригинал открывается по ссылке.
- Метаданные фиксируются при сборке, браузер не обращается ни к какому API.
- На сайте нет сумм покупок, истории сделок и остатков кошелька.
- Галерея: фильтр по разделу и коллекции; фильтр по признакам появляется после выбора коллекции.

Открытые вопросы:

- Казахские тексты – черновой перевод, нужна вычитка носителем (`src/i18n/ui.ts`, `src/content/flagships.ts`, `src/content/blog/kk/`).
- «Обо мне» содержит только известные факты, владельцу стоит дописать своё.

## Проверка перед публикацией

1. Число токенов на сайте совпадает с кошельком без скрытых, сверить на Etherscan.
2. Каждый доступный оригинал открывается, разрешение не ниже исходного.
3. Ключей API и `.env` нет в репозитории: `git log -p | grep -i "api[_-]key"` пуст.
4. Скорость на мобильном: сетки не тянут оригиналы.
5. Полный прогон скила `web-design-audit` (все шаблоны × все темы × 3 языка × 375/768/1024/1440 px), CRITICAL и HIGH закрыты.
6. Права на изображения. Показ своих NFT на личной некоммерческой витрине – обычная практика. Перед любым коммерческим применением (мерч, платный доступ, реклама) проверить лицензию каждой коллекции отдельно.

## Как работать с агентом в этом проекте

- Решения по структуре кода и компоновке страниц агент принимает сам и фиксирует их в этом файле.
- Установка ПО на машину, ввод ключей, публикация и покупка домена – действия владельца, агент к ним не приступает. Зависимости проекта через `npm install` – не установка ПО на машину.
- Готовые скрипты и код пишутся в репозиторий, а не в чат.
- Текстовые файлы с кириллицей не редактировать через PowerShell `Get-Content`/`Set-Content`: портится кодировка. Только Edit/Write или Node.
